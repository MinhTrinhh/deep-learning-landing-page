Problem Statement & Scope

The goal of Assignment 1 is to build an end-to-end deep learning pipeline for controlled-scale image classification, comparing five distinct neural architecture families under strict fairness constraints (same data split, identical evaluation protocol, and seed controls).

Key Constraints & Datasets
  • Development & Debugging Dataset: MNIST
  • Primary Results Dataset: Fashion-MNIST (10 classes, 28x28 grayscale images)
  • Optional Extension: CIFAR-10 dataset evaluation
  • Mandatory Models: Linear/Softmax, MLP, CNN, LSTM/GRU, Transformer

Comparison from the completed run

The MLP improves test accuracy by 12.02 percentage points and macro F1 by 0.1274 over the linear baseline. The trade-off is substantially higher capacity (567,434 vs. 7,850 parameters), a 1.48× longer measured training time, and slower measured inference. These timings are specific to this Colab session and batched CPU benchmark; they should not be treated as hardware-independent constants.

The MLP improves the F1 score for every class. Shirt remains the hardest category (F1 0.6135 for MLP versus 0.3040 for Linear), consistent with its visual overlap with T-shirt/top, Pullover, and Coat. The best checkpoints were selected at epoch 20 for Linear and epoch 31 for MLP using validation loss, before final evaluation on the untouched test set.
