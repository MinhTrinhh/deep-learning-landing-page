Problem Statement & Scope

The goal of Assignment 1 is to build an end-to-end deep learning pipeline for controlled-scale image classification, comparing five distinct neural architecture families under strict fairness constraints (same data split, identical evaluation protocol, and seed controls).

Key Constraints & Datasets
  • Development & Debugging Dataset: MNIST
  • Primary Results Dataset: Fashion-MNIST (10 classes, 28x28 grayscale images)
  • Optional Extension: CIFAR-10 dataset evaluation
  • Mandatory Models: Linear/Softmax, MLP, CNN, LSTM/GRU, Transformer

Dataset Description & Exploratory Data Analysis

Primary Dataset: Fashion-MNIST (60,000 training images, 10,000 test images).

Split Policy: 50,000 Train / 10,000 Validation / 10,000 Test (Stratified split with seed 42).

EDA Checklist
  • Class distribution: Balanced (6,000 samples per class in train)
  • Input tensor shape: [B, 1, 28, 28]
  • Pixel range: Normalized to [0.0, 1.0] with mean/std normalization
  • Data augmentations: RandomHorizontalFlip, RandomRotation(10)

Architectural Inductive Bias & Analysis

Inductive Bias Trade-off Discussion

CNNs vs. Flattened Models: CNNs leverage spatial locality and translation equivariance, resulting in lower parameter counts and superior performance on spatial structures compared to MLPs.

Transformers vs. Recurrent Models: ViT relies on global self-attention across image patches with weak inductive bias, requiring careful positional encodings and regularization, whereas LSTMs process images sequentially row-by-row with recurrent hidden state persistence.
