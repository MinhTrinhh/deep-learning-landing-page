Problem Statement & Scope

The goal of Assignment 1 is to build an end-to-end deep learning pipeline for controlled-scale image classification, comparing five distinct neural architecture families under strict fairness constraints (same data split, identical evaluation protocol, and seed controls).

Key Constraints & Datasets
  • Development & Debugging Dataset: MNIST
  • Primary Results Dataset: Fashion-MNIST (10 classes, 28x28 grayscale images)
  • Optional Extension: CIFAR-10 dataset evaluation
  • Mandatory Models: Linear/Softmax, MLP, CNN, LSTM/GRU, Transformer

Architectural Inductive Bias & Analysis

Each architecture encodes different assumptions about how pixels relate to one another. The measured results below are reported only for completed experiments; LSTM/GRU and ViT remain planned models.

01
Implemented baseline

Linear / Softmax

73.78% accuracy

Inductive bias. After flattening the image, each class score is an additive weighted sum of individual pixels. The model assumes a single linear decision boundary and treats every pixel position independently, with no explicit notion of locality, edges, or translation.

Observed behavior. Its 7,850 parameters make it the smallest and fastest model, but its limited capacity produces the lowest macro F1 (0.7286). Shirt is especially difficult (F1 0.3040), showing that a linear boundary cannot separate visually overlapping upper-body classes well.

02
Implemented dense model

Multilayer Perceptron

85.80% accuracy

Inductive bias. ReLU hidden layers allow nonlinear combinations of all 784 pixels, so the MLP can learn more complex global decision boundaries than the Linear model. However, flattening still removes the explicit 2D neighborhood structure, and dense layers do not share weights across image locations.

Observed behavior. The MLP improves macro F1 to 0.8560, a gain of 0.1274 over Linear, but grows to 567,434 parameters. Dropout helps regularize the larger network. Shirt remains the hardest class (F1 0.6135), although performance improves substantially over the baseline.

03
Implemented spatial model

Convolutional Neural Network

92.55% accuracy

Inductive bias. Local 3×3 receptive fields preserve the 2D image layout, while shared convolution filters detect the same feature at different positions. Pooling adds approximate translation invariance and builds a hierarchy from edges to clothing parts and shapes.

Observed behavior. This image-specific bias produces the best macro F1 (0.9259) and raises Shirt F1 to 0.7762. The gain comes with the largest completed model (1.69M parameters), 2,025.71 seconds of CPU training, and the slowest measured inference.

04
Planned experiment

LSTM / GRU

Results TBD

Inductive bias. A recurrent model would interpret each image as an ordered sequence, for example 28 rows of 28 features. Shared recurrent weights favor sequential dependencies and the hidden state carries information from earlier rows to later rows.

Expected trade-off. Recurrence can model long-range relationships, but the chosen scan order introduces a directional bias and represents 2D neighborhoods less naturally than convolution. Accuracy and efficiency claims are deferred until the architecture and experiment are completed.

05
Planned experiment

Vision Transformer

Results TBD

Inductive bias. ViT would divide the image into patches and use self-attention to model pairwise relationships between all patch tokens. Positional embeddings supply spatial order, while attention provides a flexible global receptive field with weaker built-in locality than a CNN.

Expected trade-off. Global attention can capture distant interactions directly, but its weaker image-specific prior often requires more data or stronger regularization. Patch size, depth, parameter count, and measured performance remain TBD.
