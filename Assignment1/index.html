Problem Statement & Scope

The goal of Assignment 1 is to build an end-to-end deep learning pipeline for controlled-scale image classification, comparing five distinct neural architecture families under strict fairness constraints (same data split, identical evaluation protocol, and seed controls).

Key Constraints & Datasets
  • Development & Debugging Dataset: MNIST
  • Primary Results Dataset: Fashion-MNIST (10 classes, 28x28 grayscale images)
  • Optional Extension: CIFAR-10 dataset evaluation
  • Mandatory Models: Linear/Softmax, MLP, CNN, LSTM/GRU, Transformer

  • GRU improves on MLP by 2.56 accuracy points and 0.0261 macro F1 while using 89.1% fewer parameters and an 89.1% smaller model file.

Error Analysis

  • Shirt is the hardest class. It is the weakest class for every model. ViT correctly identifies 568 of 1,000 Shirts.
  • ViT mixes up similar upper-body garments. Of the 432 missed Shirts, it predicts T-shirt/top 165 times, Coat 119 times, and Pullover 108 times. Their silhouettes overlap at 28 × 28 resolution.
  • Other ViT confusions: Pullover is mistaken for Coat 64 times, Coat for Pullover 71 times, and Sandal for Sneaker 81 times.
  • CNN makes fewer errors in these groups. This is consistent with convolution filters preserving local garment details.

Limitations & Conclusion

  • Limited repeatability: results use one random seed and one fixed configuration. Exact CPU hardware was not recorded, so runtime comparisons are indicative rather than hardware-controlled.
  • Limited dataset scope: Fashion-MNIST has small, centered grayscale images. These results do not establish how well the models generalize to color images or cluttered scenes.
  • No matched-factor ablation: the experiments do not isolate the effect of each individual design choice.
  • Best measured performance: CNN achieves 92.55% test accuracy and 0.9259 macro F1.
  • Different practical trade-offs: Linear is the smallest and fastest model; GRU offers a compact accuracy-to-parameter trade-off; ViT reaches 87.93% accuracy but has the highest measured inference cost.
  • Conclusion for this setup: preserving local image structure with convolutions worked better on Fashion-MNIST than using ViT's global patch attention.

Architectural Inductive Bias & Discussion

Each architecture encodes different assumptions about how pixels relate to one another. Observations for all five models are based on the completed experiments.

01
Implemented baseline

Linear / Softmax

73.78% accuracy

Inductive bias. After flattening the image, each class score is an additive weighted sum of individual pixels. The model assumes a single linear decision boundary and treats every pixel position independently, with no explicit notion of locality, edges, or translation.

Observed behavior. Its 7,850 parameters make it the smallest and fastest model, but its limited capacity produces the lowest macro F1 (0.7286). Shirt is especially difficult (F1 0.3040), showing that a linear boundary cannot separate visually overlapping upper-body classes well.

02
Implemented dense model

Multilayer Perceptron

85.80% accuracy

Inductive bias. ReLU hidden layers allow nonlinear combinations of all 784 pixels, so the MLP can learn more complex global decision boundaries than the Linear model. However, flattening still removes the explicit 2D neighborhood structure, and dense layers do not share weights across image locations.

Observed behavior. The MLP improves macro F1 to 0.8560, a gain of 0.1274 over Linear, but grows to 567,434 parameters. Dropout helps regularize the larger network. Shirt remains the hardest class (F1 0.6135), although performance improves substantially over the baseline.

03
Implemented spatial model

Convolutional Neural Network

92.55% accuracy

Inductive bias. Local 3×3 receptive fields preserve the 2D image layout, while shared convolution filters detect the same feature at different positions. Pooling adds approximate translation invariance and builds a hierarchy from edges to clothing parts and shapes.

Observed behavior. This image-specific bias produces the best macro F1 (0.9259) and raises Shirt F1 to 0.7762. The gain comes with the largest model (1.69M parameters), 2,025.71 seconds of CPU training, and the slowest inference among the four non-Transformer models; ViT is slower still.

04
Implemented recurrent model

Gated Recurrent Unit

88.36% accuracy

Inductive bias. The GRU interprets each image as 28 ordered rows of 28 features. Shared recurrent weights favor sequential dependencies, and its 128-dimensional hidden state carries information from earlier rows to later rows.

Observed behavior. GRU reaches 0.8821 macro F1, outperforming MLP with about one-ninth as many parameters. Its sequential structure is useful, but recurrent processing is slower than dense computation and the top-to-bottom scan represents 2D locality less naturally than CNN. Shirt remains hardest (F1 0.6689), while Trouser, Bag, Ankle boot, and Sandal all exceed 0.96 F1.

05
Implemented and evaluated

Vision Transformer

87.93% accuracy

Inductive bias. ViT divides the image into 49 patches and uses self-attention to model relationships between all 50 tokens, including the class token. Learned positional embeddings supply spatial order, while attention provides a global receptive field with weaker built-in locality than a CNN.

Observed behavior. ViT reaches 87.93% accuracy and 0.8771 macro F1, slightly below GRU. Its 803,338 parameters and 0.264764 ms/sample inference time make it substantially more costly than the recurrent model. Shirt is its weakest class (recall 0.568); the confusion matrix shows frequent confusion with T-shirt/top, Coat, and Pullover.
