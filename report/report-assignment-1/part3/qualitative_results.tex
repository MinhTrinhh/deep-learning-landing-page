\section{Qualitative Results}

Figure~\ref{fig:qualitative-results} compares predictions from the restored Linear, MLP, CNN, GRU, and ViT checkpoints on the same Fashion-MNIST test examples. The selected rows include examples all models classify correctly, cases where structured models recover an example missed by a baseline, cases where CNN is correct but another model is not, and examples all models misclassify.
