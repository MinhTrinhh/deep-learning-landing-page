\section{Baseline and Main Methods}

All five architectures and their forward-pass wiring were designed for this assignment using PyTorch modules; they are not pretrained models. The convolutional, linear, recurrent, attention, activation, pooling, normalization, and dropout operations use PyTorch's library layers. Models receive a batch of normalized grayscale images with shape $[B,1,28,28]$ and return ten raw class scores (logits) per image. The code snippets below show each implemented forward pass; each model's diagram, code, and discussion are grouped together for easier comparison.

\subsection*{Linear / softmax baseline}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{graphics/models/linear-model.png}
    \caption{Linear classifier architecture.}
    \label{fig:linear-architecture}
\end{figure}
\textbf{Forward function.} The code flattens each image while preserving the batch dimension, then passes the resulting 784-value vector through the linear layer. The result contains ten logits per image.
\begin{lstlisting}
def forward(self, images):
    vectors = torch.flatten(images, start_dim=1, end_dim=-1)
    return self.fc(vectors)
\end{lstlisting}
The returned values are logits; softmax is used only when class probabilities are needed, since cross-entropy loss consumes logits directly.

\textbf{Discussion.} This is the simplest baseline: each output class is a weighted sum of all 784 pixels. It is fast and provides a useful reference point, but has no hidden nonlinear transformations and does not explicitly represent local spatial patterns.

\subsection*{Multilayer perceptron}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{graphics/models/mlp-model.png}
    \caption{MLP architecture with nonlinear hidden layers and dropout.}
    \label{fig:mlp-architecture}
\end{figure}
\textbf{Forward function.} The input is flattened, then passed through three linear--ReLU--dropout stages and a final linear layer that returns ten logits.
\begin{lstlisting}
def forward(self, images):
    vectors = torch.flatten(images, start_dim=1, end_dim=-1)

    out = self.fc1(vectors)
    out = self.relu1(out)
    out = self.drop1(out)

    out = self.fc2(out)
    out = self.relu2(out)
    out = self.drop2(out)

    out = self.fc3(out)
    out = self.relu3(out)
    out = self.drop3(out)

    out = self.fc4(out)
    return out
\end{lstlisting}

\textbf{Discussion.} The three hidden layers allow nonlinear combinations of pixels and have substantially more representational capacity than the linear baseline. Flattening the image before processing, however, means that neighboring pixels are not treated specially and the model does not preserve a two-dimensional feature map.

\subsection*{Convolutional neural network}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{graphics/models/cnn-model.png}
    \caption{CNN spatial feature extractor and dense classifier.}
    \label{fig:cnn-architecture}
\end{figure}
\textbf{Forward function.} The feature extractor applies two convolutional blocks (convolution, ReLU, max pooling). Its output is passed to the dense classifier, which returns ten logits.
\begin{lstlisting}
def forward(self, images):
    features = self.features(images)
    logits = self.classifier(features)
    return logits
\end{lstlisting}
The operations inside \texttt{self.features} and \texttt{self.classifier} are the layers defined in the model constructor.

\textbf{Discussion.} Convolutions learn local filters and reuse the same weights across image locations; pooling reduces spatial resolution while retaining strong responses. These properties make the CNN well matched to image structure. Its dense classifier then combines the extracted spatial features to predict a clothing class.

\subsection*{Gated recurrent unit}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{graphics/models/gru-model.png}
    \caption{GRU row-sequence representation, recurrent hidden state, and classifier.}
    \label{fig:gru-architecture}
\end{figure}
\textbf{Forward function.} The channel dimension is removed to represent the 28 image rows as a sequence. The GRU processes that sequence; its final hidden state is passed through dropout and the classifier.
\begin{lstlisting}
def forward(self, images):
    sequences = images.squeeze(1)
    _, hidden = self.gru(sequences)

    final_hidden = self.dropout(hidden[-1, :, :])
    logits = self.classifier(final_hidden)
    return logits
\end{lstlisting}
The recurrent stage has $3HI+3H^2+6H=60{,}672$ parameters for input size $I=28$ and hidden size $H=128$; the classifier adds 1,290 parameters.

\textbf{Discussion.} The GRU can carry information from earlier rows to later rows, allowing the final state to summarize the image as a sequence. This imposes a top-to-bottom ordering on a two-dimensional object and does not retain local two-dimensional structure as directly as a CNN.

\subsection*{Vision Transformer}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{graphics/models/vit-model.png}
    \caption{Vision Transformer patch projection, class and position tokens, encoder stack, and classifier.}
    \label{fig:vit-architecture}
\end{figure}
\textbf{Forward function.} The convolution creates patch embeddings. The forward pass then prepends the class token, adds position embeddings, encodes the tokens, and classifies the encoded class token.
\begin{lstlisting}
def forward(self, images):
    patches = self.patch_embedding(images).flatten(2).transpose(1, 2)
    class_tokens = self.class_token.expand(images.shape[0], -1, -1)
    tokens = torch.cat((class_tokens, patches), dim=1)
    tokens = self.embedding_dropout(tokens + self.position_embedding)
    encoded = self.encoder(tokens)
    image_representation = self.norm(encoded[:, 0])
    return self.classifier(image_representation)
\end{lstlisting}
Here \texttt{encoded[:, 0]} selects the encoded class token for each image in the batch.
Each encoder layer uses a 512-dimensional feed-forward block with GELU activation and dropout $p=0.2$. The model has 803,338 trainable parameters: 2,176 in the patch projection, 6,528 in the class and position embeddings, 793,088 in the encoder, 256 in final normalization, and 1,290 in the classifier.

\textbf{Discussion.} Self-attention lets each patch representation combine information from all other patches, while learned position embeddings provide information about where each patch came from. The class token serves as a learned summary passed to the classifier. In the recorded run, ViT reaches 87.93\% test accuracy and 0.8771 macro-F1, below the CNN and GRU. Its 0.265 ms per-image inference time is the slowest measured, consistent with the cost of attention over 50 tokens.
